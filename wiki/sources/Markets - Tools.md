# Markets - Tools

A short list of market tools from Erlin's notes. Two are live dashboards for crypto market structure: liquidations and [[Hyperliquid]] network latency. The third is [[Gloomberb]], an open-source research terminal.

## Liquidations and positioning

- [Real-time liquidations](https://loris.tools/liquidations) — Live liquidations tracker on loris.tools. Shows forced closes across markets as they happen, which is useful context for [[Positioning]] and risk. See [[Liquidations]].

## Hyperliquid infrastructure

- [Hyperliquid latency map](https://hyperlatency.glassnode.com/?utm_source=X&utm_medium=social&utm_campaign=hyperliquid) — Glassnode's latency map for [[Hyperliquid]]. Monitors network latency, which matters for high-frequency trading and [[Exchange Microstructure]].

## Research terminal

- [Gloomberb](https://github.com/vincelwt/gloomberb) — Open-source, keyboard-driven finance terminal with desktop and terminal interfaces. Covers watchlists, filings, macro data, alerts and market research. Check its upstream data sources before using it for trading decisions. See [[Gloomberb]] and [[Trading Platforms]].
