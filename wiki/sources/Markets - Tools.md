## Real-Time Tools

### Liquidations Monitor
- **Real-time Liquidations**: https://loris.tools/liquidations
- Tracks active liquidations across markets for positioning and risk insights

### Hyperliquid Infrastructure
- **Hyperliquid Latency Map**: https://hyperlatency.glassnode.com/?utm_source=X&utm_medium=social&utm_campaign=hyperliquid
- Monitors network latency and microstructure for high-frequency trading context

### Open-source finance terminal

- **[[Gloomberb]]**: https://github.com/vincelwt/gloomberb
- Keyboard-driven desktop and terminal interfaces for watchlists, filings, macro data, alerts, and research. Verify every upstream data source before using it for trading decisions.
