# Setup

A short inventory of the tools in Erlin's setup note, one setup guide, and a self-hosting platform on watch. Most tools are listed by name only; the note gives a description for Zero Brew and Handy.

## Core development

- **mole** — Listed by name only.
- **Codex / Claude Code** — AI coding agents.
- **Zero Brew** — The note calls it an "alternative to brew" (Homebrew, the macOS package manager).
- **bun** — JavaScript runtime and package manager.
- **Obsidian** — Note-taking and knowledge-management app.

## System and utilities

- **Helium** — Listed by name only. The wiki's [[Helium Browser]] page covers the Chromium-based browser of that name.
- **Handy** — Voice transcription.

## Setup guides

- [OpenClaw on Mac Mini: The Complete Setup Guide](https://robertheubanks.substack.com/p/openclaw-on-mac-mini-the-complete?utm_campaign=post-expanded-share&utm_medium=web&triedRedirect=true) — Substack guide to running OpenClaw on a Mac Mini.

## Self-hosted platform watchlist

- [OpenShip](https://openship.io/) — Open-source application deployment and operations platform for infrastructure you control. See [[OpenShip]].

The note treats OpenShip as a product to evaluate, not a verified production dependency. Before adopting it, test:

- restore from backup;
- rollback under failure;
- secrets and access controls;
- monitoring and alert delivery;
- outbound-email reputation and deliverability from a clean server.
