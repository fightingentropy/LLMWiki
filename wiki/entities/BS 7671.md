# BS 7671 and GN3

BS 7671, the IET Wiring Regulations, sets the technical requirements for electrical installations in the UK. Guidance Note 3 (GN3): Inspection & Testing is the IET's guide to verifying an installation against it; it is not an HSE publication.

## Current editions

- **BS 7671:2018+A4:2026** is the only current edition. [BSI](https://knowledge.bsigroup.com/articles/bs-7671-2018-a4-2026-get-the-latest-amendment-to-the-uks-wiring-regulations) withdrew BS 7671:2018+A2:2022+A3:2024 on 15 October 2026. A4 adds batteries, ICT bonding, Power over Ethernet and medical locations.
- The [IET edition checker](https://electrical.theiet.org/bs-7671-18th-edition-wiring-regulations/ensure-you-are-up-to-date-with-bs-7671/) still shows the transition wording, and its errata section names A2 rather than A3.
- **GN3 tenth edition** and the **On-Site Guide ninth edition** are the [IET's A4 books](https://electrical.theiet.org/guidance-and-codes-of-practice/publications-by-category/amendment-42026-to-bs-76712018-iet-wiring-regulations/bs-7671-and-guidance/).
- The A3 introduction says an installation built to an earlier edition is not necessarily unsafe or in need of upgrading.

Correction, 16 October 2026: the A3 edition is no longer valid; the transition ended on 15 October 2026.

Correction, 22 September 2026: GN3 is tenth edition, not fifth; the earlier description mixed it with the fifth-edition in-service Code of Practice.

## Using them

- Record the edition used for each job, and check the errata.
- A study page is not the standard. Read the clause itself for conditions, exceptions and definitions.
- Page and table numbers do not carry between editions.
- For each test, find in GN3 its purpose, the safe state needed, the instrument, the limits and what to record.
- Appliance testing follows the separate IET Code of Practice; see [[In-Service Testing]].
