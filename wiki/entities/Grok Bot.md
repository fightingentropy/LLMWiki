# Grok Bot

Computer-using agent product presented for scheduled routines, application access, and multi-bot work. The retained household examples—reminders, inbox triage, device administration, and shopping—are proposed workflows rather than tested capabilities in this wiki.

[[Digital Security]] controls apply: narrow each bot's role, review connected-account permissions, and require explicit approval for purchases, deletion, messages, trades, or other consequential actions.

OpenGrok is an unofficial Python patch that adds subscription/API/local-model routing, a model picker, and diagnostics. It depends on product internals and should be audited for installer behavior, credentials, licensing, network access, and account terms before use. It is unrelated to Oracle's similarly named source-browser project. (from [[X-Bookmarks]])
