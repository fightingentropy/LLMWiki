# Omarchy

Basecamp's opinionated Arch Linux and Hyprland development environment. Quattro is framed as a malleable agentic-work setup; experimental macOS demonstrations run it through Apple Containerization and Rosetta rather than establishing native macOS parity.

The source batch contains both rapid-adoption promotion and scepticism that the project is receiving credit for upstream Linux, Arch, and Hyprland work. Neither side establishes retention, support burden, originality, or paid promotion. Evaluate code, contributors, upstream dependencies, hardware compatibility, rollback, and day-to-day workflow on non-critical hardware first.

Omarchy Pods is a small AirPods-control utility for the environment; inspect Bluetooth permissions, supported models, dependencies, packaging, and maintenance before installation. (from [[X-Bookmarks]])
