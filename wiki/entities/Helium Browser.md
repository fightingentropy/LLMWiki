# Helium Browser

Helium is a Chromium-based desktop browser whose project describes default ad/tracker blocking, reduced Google-service dependencies, and consent-based browser services. [Official site](https://helium.computer/), checked 2026-09-22.

## Current documented boundaries

The official FAQ says data sync and mobile support are not yet available, Widevine-protected media is unsupported, and there is no built-in password manager. These are dated documentation claims, not results from a local installation.

## Bookmark trail

- August/September development posts discuss optional TLS ClientHello splitting and clearer debugging warnings.
- The [0.17.2 release discussion](https://x.com/cyyynthia_/status/2101259480981758225) highlights CNAME uncloaking, keychain safeguards, GPC, lazy tab restoration, and interface work.

Release-specific claims remain attached to their dates. Browser privacy, network compatibility, extension trust, and update behaviour require separate evaluation; see [[Digital Security]]. (from [[Bookmarks - Developer Tools]])
